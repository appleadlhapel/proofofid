PROOFOFID

Proof of work, bound to your Agent ID.

Solve a daily nonce challenge in your browser, sign an EIP-712 attestation, and lock it in as a soulbound on-chain badge on BNB Chain. No tradable token, no custody of funds.

Step 1 — Connect wallet & check Agent ID

The contract checks AgentID.balanceOf(address) > 0 before accepting an attestation. Get an Agent ID in the Binance App: Wallet > Agent ID banner.

Security

  1. Never asks for a seed phrase, private key, pairing code, or QR login. This site has no login session.
  2. Every transaction still needs confirmation from your own wallet.
  3. The contracts hold no funds, have no tradable token, and promise no returns.
  4. Owner permissions are documented: setDifficulty (PoWAttestor) and setBaseURI (ProofBadge).
