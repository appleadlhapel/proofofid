Proof of work, bound to your Agent ID.

Selesaikan challenge nonce harian di browser, tanda tangani atestasi EIP-712, dan kunci sebagai badge soulbound on-chain di BNB Chain. Tanpa token tradable, tanpa kustodi dana.

Keamanan

  1. Tidak pernah minta seed phrase, private key, pairing code, atau login QR. Situs ini tidak punya sesi login.
  2. Setiap transaksi tetap butuh konfirmasi dari wallet kamu sendiri.
  3. Kontrak tidak menyimpan dana, tidak punya token tradable, tidak menjanjikan return.
  4. Izin owner terdokumentasi: setDifficulty (PoWAttestor) dan setBaseURI (ProofBadge).
